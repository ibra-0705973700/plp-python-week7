# Week 7 Assignment: My Notes & The Report Builder

- `my_notes.py`: Writes, appends, reads, and counts lines in a text file using `with open(...)`.
- `my_notes.txt`: Text file generated by `my_notes.py` containing four saved notes.
- `report_builder.py`: Reads learner records from `hubs.csv`, handles missing files safely, and writes summary statistics to `report.txt`.
- `hubs.csv`: Input CSV dataset containing learner names, hubs, and scores.
- `report.txt`: Generated summary report showing total learners, passed, failed, and average score.
- `README.md`: Documentation describing the assignment files and file-mode behavior.

## Changing `"a"` to `"w"` in Question 1

If you change `"a"` (append mode) to `"w"` (write mode) when adding the fourth note, Python will erase the first three lines already in `my_notes.txt` before writing `"I added this later\n"`. As a result, the file would only contain 1 line instead of 4.
